How this is maintained

Each country is a markdown file with structured metadata, kept in git, so every change to a legal claim is a reviewed diff with a date attached. An entry that claims to be verified must name who verified it and when, and goes stale after 90 days. What could not be established is recorded as an open question rather than quietly dropped.
