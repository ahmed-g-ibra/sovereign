Contact and corrections

This site publishes measurements and legal summaries that affect real architecture decisions. If something here is wrong, the fastest way to fix it is to tell us, and every correction route below is a public one.

Report an error

Open an issue on GitHub. That is the preferred channel for everything: a measurement that looks wrong, a residency entry that misreads the law, a broken endpoint, a region we have not added yet.

Public and threaded, so a correction and its evidence stay attached to the claim they fixed. Private email cannot do that.

Something that should not start in public

There is no private channel yet. If you need one — a security report, or a correction you would rather not raise publicly — open an issue saying so without the details, and we will find a way to take it off-list.

If you operate a network we measure

We send a small number of ICMP echo requests and TLS handshakes on a fixed schedule, to published endpoints, from a published list of probes. The full method is in the methodology, including every endpoint we touch.

If our traffic is a problem for you, open an issue and we will stop measuring your network. We are measuring the internet, not testing anyone's patience.

Run a probe

The measurements are only as good as the number of vantage points. If you have a connection in the Gulf — home, office, a small VPS — you can contribute one. The agent is a single binary with no dependencies, it needs no root, and it measures outbound only: it opens no ports and reads nothing about your network beyond the route to a handful of cloud endpoints.

Source and setup instructions

There is currently one probe. Every additional one makes every figure on this site more defensible.

What this is not

  • Not legal advice. The residency pages summarise legislation for engineers choosing a region. They are not a substitute for a qualified practitioner in the relevant jurisdiction, and several entries are explicitly marked draft.
  • Not a cloud provider ranking. Latency from one set of vantage points is one input among many.
  • Not affiliated with any cloud provider, telecom operator or regulator.
